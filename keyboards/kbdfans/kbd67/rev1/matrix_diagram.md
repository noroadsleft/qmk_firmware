# Matrix Diagram for KBDfans KBD67 Rev1

Based on the research I've done, this PCB supports the full Tada68
layout (6x 1u on the bottom row). However, this PCB was also included in
a KBD65 keyboard kit when originally released, and the case included
with that kit only supported 0.5u-blockered layouts.
